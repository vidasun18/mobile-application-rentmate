# Architecture

Flutter (Provider, HTTP, secure storage, Hive) → Express REST API → SQLite file locally, or PostgreSQL for shared deployment. The user's 18 October instruction authorizes the local database alternative. `npm run local` generates persistent configuration, runs SQLite migrations and seeds only an empty database. No Python database service or MongoDB installation is required. The API is the authority for access, eligibility, transitions and serialization.

Tables use foreign keys, checks and unique constraints. Money is integer LKR cents. PostgreSQL tour mutations lock the tour row. SQLite uses STRICT tables, foreign keys, WAL, `BEGIN IMMEDIATE` and a queue covering each complete transaction; ordinary reads cannot interleave into another request's transaction. Its adapter translates the application's small set of PostgreSQL expressions and binds all values. Times normalize to UTC ISO strings before storage. Both versions have a partial unique active-assignment index. Native SQLite migrations mirror the five PostgreSQL migrations; upgrades must provide both dialects. Send uses an Idempotency-Key scoped to the assignment. Reopen ends the active assignment. Ended driver history preserves a non-contact snapshot instead of revealing later pickup changes. Role serializers construct allowlists. Private admin reads require a reason and audit record.

Notification inbox rows are committed with business changes. Notifications carry explicit tour/membership/account destinations. Push delivery uses a retryable outbox state with generic text/resource IDs. Firebase is optional and honestly unavailable without credentials. Local mode stores uploaded bytes under UUID filenames outside public static routes. Private document and pending-photo views require a 60-second signed media token tied to an owner/admin and token version. Each fetch rechecks current permissions. Administrative view-token issuance is audited with its reason. Public local photo fetches require approval and an approved owner. Cloudinary authenticated storage/delivery remains an optional configured adapter. The mobile document viewer evicts its decoded network image when closed.

Offline storage is account scoped and restricted to non-contact trip summaries and their read-only detail page. Online refresh replaces cached records; logout clears them. A disconnected device cannot learn about a server revocation; avoiding contacts/documents in the cache limits exposure. Privileged writes are never queued offline.
